# patrickhilker/homebrew-tap

Homebrew formulae.

```sh
brew install patrickhilker/tap/agentmail
```

| Formula | Description |
|---|---|
| [agentmail](https://github.com/patrickhilker/agentmail) | Email for AI agents on a catch-all IMAP/SMTP mailbox |

The formulae are updated automatically by the release workflows of their projects.
